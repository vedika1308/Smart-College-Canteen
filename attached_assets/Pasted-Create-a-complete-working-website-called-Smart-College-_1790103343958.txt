Create a complete working website called “Smart College Canteen Pre-Order & Token Management System” for a college mini-project.

Technology

Use:

- PHP
- MySQL
- HTML5
- CSS3
- JavaScript
- Bootstrap 5 if needed
- The website must work on XAMPP localhost
- Database must be compatible with MySQL/phpMyAdmin
- Keep the code simple and suitable for a college student to understand and explain.

Main Objective

The website should allow college students to view the canteen menu, select food items, add them to a cart, place a pre-order and receive a digital token number. The canteen/admin should be able to view and manage orders.

Website Pages

1. Home Page — index.php

Create a modern college-canteen homepage with:

- Website name: Smart College Canteen
- Navigation bar
- Home
- Menu
- My Orders
- Login/Register
- Attractive hero section
- Short description of the system
- “Order Now” button
- Benefits section:
  - Reduces waiting time
  - Reduces queues
  - Easy pre-ordering
  - Digital token system
  - Organized order management

2. Student Registration — register.php

Create a registration form with:

- Full Name
- Student ID/Roll Number
- Email
- Mobile Number
- Password
- Confirm Password

Store registered users securely in MySQL.

3. Student Login — login.php

Create login functionality using:

- Email
- Password

Use PHP sessions for authentication.

4. Menu Page — menu.php

Display food items using cards.

Each food card should contain:

- Food image
- Food name
- Description
- Price
- Availability
- Add to Cart button

Example menu:

- Veg Sandwich — ₹40
- Masala Dosa — ₹60
- Vada Pav — ₹20
- Veg Burger — ₹50
- Samosa — ₹20
- Pizza — ₹80
- Cold Drink — ₹30
- Tea — ₹15
- Coffee — ₹25

Allow the admin to add, edit and delete menu items.

5. Cart — cart.php

Show:

- Selected food items
- Quantity
- Price
- Subtotal
- Total amount
- Increase/decrease quantity
- Remove item
- “Place Pre-Order” button

6. Order Page — order.php

After the student places an order:

- Save the order in MySQL.
- Generate a unique digital token number.
- Display:
  - Order ID
  - Digital Token Number
  - Ordered items
  - Total amount
  - Order date/time
  - Order status

Default status should be:
Pending

7. Order Status — order_status.php

Allow students to view their current order status.

Statuses:

- Pending
- Confirmed
- Preparing
- Ready for Pickup
- Completed
- Cancelled

Use clear status badges.

8. Student Dashboard

Create a simple dashboard where the student can:

- View profile
- View current order
- View previous orders
- View digital token
- Logout

9. Admin Login

Create a separate admin login.

Admin credentials can initially be:
Email: admin@canteen.com
Password: admin123

Store admin login securely in the database if possible.

10. Admin Dashboard — admin.php

Create an attractive dashboard showing:

- Total Orders
- Pending Orders
- Preparing Orders
- Ready Orders
- Completed Orders
- Total Revenue

Admin should be able to:

- View all orders
- View order details
- Update order status
- Add food items
- Edit food items
- Delete food items
- Mark food as available/unavailable
